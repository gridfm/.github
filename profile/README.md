## Hi there 👋

**Welcome to the OpenGridFM organization README**

🙋‍♀️ A short introduction - what is our organization all about?

An open development framework for foundation models of the electric grid. An [LF Energy](https://lfenergy.org/projects/opengridfm/) project.

👩‍💻 Useful resources - where can the community find docs?

- [Project page](https://lfenergy.org/projects/opengridfm/)
- [Community](https://gridfm.org)
- [Data generation: gridfm-datakit](https://github.com/gridfm/gridfm-datakit) · [docs](https://gridfm.github.io/gridfm-datakit/)
- [Training and inference: gridfm-graphkit](https://github.com/gridfm/gridfm-graphkit) · [docs](https://gridfm.github.io/gridfm-graphkit/)
- [Datasets and models](https://huggingface.co/gridfm)
- [Paper (GENCO)](https://arxiv.org/abs/2608.09921)
- [License: Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0)

🌈 Contribution guidelines - how can the community get involved?

- Open an issue or pull request on [gridfm-datakit](https://github.com/gridfm/gridfm-datakit) or [gridfm-graphkit](https://github.com/gridfm/gridfm-graphkit). Follow that repository’s `CONTRIBUTING.md`.
